
### 3단계: ROADMAP.md 체크박스 업데이트

`docs/ROADMAP.md` 파일을 읽습니다.

**done 상태인 태스크**에 해당하는 마일스톤 섹션의 **모든** `- [ ]` 항목을 `- [x]`로 변경합니다.

- 섹션 범위: 해당 마일스톤 헤더(`####`)부터 다음 `####` 헤더 직전까지
- 중첩 들여쓰기 항목(하위 리스트)도 포함하여 모두 체크
- `- **산출물**`, `- **완료 기준**`, `- **리스크**` 라인은 체크박스가 없으므로 수정하지 않음

**pending 또는 in-progress 상태인 태스크**의 마일스톤 섹션은 변경하지 않습니다.

### 4단계: 핵심 목표 체크박스 업데이트

`## 🎯 핵심 목표` 섹션의 항목은 전체 Phase 완료 기준으로 업데이트합니다:

- Phase 0 전체(태스크 1-4) 완료 → "Notion API를 활용한 독서 기록 CMS 구축" 체크
- Phase 1 전체(태스크 5-8) 완료 → "반응형 UI로 모든 기기에서 최적의 사용자 경험 제공" 체크
- Phase 2 전체(태스크 9-12) 완료 → "독서 상태별(읽고 싶음/읽는 중/완독) 필터링 및 관리" 체크
- Phase 2 성능 최적화(태스크 11) 완료 → "2초 이내 페이지 로드 성능 달성" 체크
- Phase 0 타입 시스템(태스크 3) 완료 → "TypeScript 타입 안정성 100% 확보" 체크

### 5단계: 진행 상황 요약 테이블 업데이트

`## 📊 진행 상황 요약` 섹션의 테이블을 실제 완료율로 업데이트합니다.

완료율 계산 기준:
- **Phase 0** (태스크 1-4): 4개 중 완료 수 / 4 × 100%
- **Phase 1** (태스크 5-8): 4개 중 완료 수 / 4 × 100%
- **Phase 2** (태스크 9-12): 4개 중 완료 수 / 4 × 100%
- **Phase 3** (태스크 13-16): 4개 중 완료 수 / 4 × 100%
- **Phase 4** (태스크 17-21): 5개 중 완료 수 / 5 × 100%
- **전체**: 21개 중 총 완료 수 / 21 × 100%

상태 아이콘 기준:
- 0% → `🔲 대기`
- 1%~99% → `🔄 진행 중`
- 100% → `✅ 완료`

### 6단계: 변경 이력 추가

`## 📝 변경 이력` 테이블 맨 아래에 오늘 날짜로 새 행을 추가합니다:

```
| YYYY-MM-DD | task-master 완료 상태 반영 (태스크 X, Y, Z → done) | /docs:update-roadmap 실행 |
```

날짜는 오늘 날짜(`currentDate`)를 사용합니다.

### 7단계: 최종 업데이트 날짜 수정

파일 맨 하단의 `**최종 업데이트**:` 값을 오늘 날짜로 변경합니다.
